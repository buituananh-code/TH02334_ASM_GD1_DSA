Dự án này là một chương trình dạng Console/Terminal viết bằng Python dùng để quản lý danh sách đơn hàng POLY-SHIP.
Chương trình sử dụng một tập dữ liệu mẫu tĩnh được lưu trong file `data.py` để thực hiện các thao tác xử lý dữ liệu cơ bản.

Các chức năng chính của chương trình bao gồm:
* Hiển thị: Xem toàn bộ danh sách đơn hàng hiện có.

* Tìm kiếm: Tìm kiếm đơn hàng theo tên khách hàng.

* Sắp xếp & Lọc: Cung cấp Menu để người dùng sắp xếp dữ liệu theo nhiều tiêu chí (Tên, Mã đơn, Thời gian, Khu vực) và lọc đơn hàng theo từng tỉnh thành cụ thể.

* Báo cáo độ phức tạp (Complexity Report): Tính năng tự động nhân bản dữ liệu để giả lập khối lượng đơn hàng lớn, qua đó đo lường số bước và thời gian chạy thực tế của các thuật toán nhằm mục đích so sánh.

- Cách chạy:
Để chạy chương trình thực hiện theo các bước sau:
    1. Tải toàn bộ các file trong repository này về và đặt vào cùng một thư mục.
    2. Mở Terminal (hoặc Command Prompt / PowerShell) tại thư mục chứa mã nguồn.
    3. Khởi chạy file hệ thống chính bằng câu lệnh: python main_assignment.py hoặc đơn giản ấn lút chạy ngay trên ;-;
